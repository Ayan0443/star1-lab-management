【服务器使用说明】

服务器 IP：10.0.0.10（校内网可直接连接）
校外访问：支持 IPv6 直连（见文末「校外 IPv6 直连」），稳定性取决于学校机房。

一、账号与权限
1. 如需使用服务器，可通过本页面自助申请账号（需在校园网内访问）。申请必须使用示例大学邮箱
   （@mails.example.edu.cn 或 @example.edu.cn）并完成邮箱验证码验证，一个邮箱只能申请一个账号；如无法申请请联系管理员。
2. 使用账号均为普通用户权限；如需安装/调整系统环境，请联系管理员。
3. 在使用过程中有任何问题，请及时联系管理员处理。

二、数据目录
新用户的家目录（工作目录）默认位于数据盘 /home/<用户名> 下，因此不存在数据挂载问题，
不需要再手动挂载数据目录。

三、GPU 使用
1. 如需使用显卡进行深度学习训练，请先用以下命令查看显卡占用情况，选择未被占用的显卡：
     watch -n 1 nvidia-smi
   也可以使用：nvtop
2. PyTorch 环境下，使用 torch.cuda.set_device(gpu_idx) 指定要使用的 GPU。

四、Python / Conda 环境（重要）
当前服务器仅可以运行 Python 代码；使用 Python 必须先创建并进入自己的 conda 环境。
创建环境：
     conda create -n <环境名称> python=<python版本>
初始化并生效：
     conda init
     source ~/.bashrc
每次登录后进入自己的环境（每次登录执行一次）：
     conda activate <环境名称>
退出当前环境：
     conda deactivate
查看已有环境（不记得环境名时）：
     conda env list
     或 conda info --envs
每个用户可创建多个 conda 环境；在自己的环境中安装包可使用 pip 或 conda install。
删除环境（先 deactivate）：
     conda env remove -n <环境名>

七、账号申请与邮箱验证（重要）
1. 申请账号必须使用示例大学邮箱：学生邮箱 @mails.example.edu.cn，教职工邮箱 @example.edu.cn。
2. 在申请页填写学校邮箱 → 点「发送验证码」→ 到邮箱查收 6 位验证码（10 分钟内有效）→ 填入后提交。
3. 一个学校邮箱只能申请一个账号；同一校园网 IP 也只能申请一个账号。
4. 收不到验证码时：先检查垃圾邮件箱；仍收不到请联系管理员（可能被邮件系统拦截或发送过于频繁）。
5. 账号申请成功后，用户名/密码只在页面显示一次，请立即保存。
6. 忘记密码：在申请页点击「忘记密码？」，用学校邮箱接收验证码即可自助重置密码；
   若账号处于锁定状态，重置后仍需联系管理员解锁。
7. 已有服务器账号的同学（老用户）：请在申请页点击「绑定已有账号邮箱」，用本人学校邮箱完成绑定
   （需输入用户名 + 当前服务器密码 + 邮箱验证码）；绑定后即可使用「忘记密码」自助重置。

八、如何配置 SSH 密钥登录（推荐）
1. 为什么要用密钥：比每次输密码更安全、更方便；私钥只保存在自己电脑上，不要发给任何人。
2. 生成密钥对（Linux / macOS / Windows PowerShell 都可以）：
     ssh-keygen -t rsa -b 4096 -C "你的学校邮箱"
   一路回车即可（默认保存到 ~/.ssh/id_rsa；可设置私钥口令 passphrase，更安全）。
   生成后会得到两个文件：
     私钥 ~/.ssh/id_rsa       —— 保密，绝不外传
     公钥 ~/.ssh/id_rsa.pub   —— 可以上传到服务器
3. 把公钥上传到服务器（任选一种）：
   方式A（Linux / macOS 推荐）：
     ssh-copy-id 你的用户名@10.0.0.10
   方式B（手动，各系统通用）：
     先登录服务器：ssh 你的用户名@10.0.0.10
     然后执行：
       mkdir -p ~/.ssh && chmod 700 ~/.ssh
       echo "把 id_rsa.pub 文件里的整行内容粘贴到这里" >> ~/.ssh/authorized_keys
       chmod 600 ~/.ssh/authorized_keys
   方式C（Windows）：用记事本打开 C:\Users\你的用户名\.ssh\id_rsa.pub，复制整行；
     按方式B 登录服务器后粘贴到 ~/.ssh/authorized_keys。
4. 验证：校内执行 ssh 你的用户名@10.0.0.10；
   校外 IPv6 执行 ssh -6 -p 2222 你的用户名@2001:db8::10
   能免密登录即配置成功。
5. 安全提醒：私钥 id_rsa 等同于密码，务必保密，不要发群/网盘；公钥 id_rsa.pub 才可以给别人；
   建议给私钥设置口令并在重装系统前备份；服务器上 ~/.ssh 权限应为 700、authorized_keys 为 600。

九、已有账号绑定学校邮箱（老用户必看）
1. 之前已开通服务器账号的同学，请到申请页点击「绑定已有账号邮箱」：
   输入「用户名 + 当前服务器密码 + 本人学校邮箱」→ 获取邮箱验证码 → 提交绑定。
2. 绑定成功后，可在申请页用「忘记密码」通过学校邮箱自助重置密码。
3. 一个学校邮箱只能绑定一个账号；已绑定邮箱的账号无需重复绑定。
4. 为安全考虑，系统已禁用「删除账号」功能；如需处理账号问题请联系管理员。
